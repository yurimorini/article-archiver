# Probe Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One command runs the real Eleanor server through a named step list and writes an observation folder.

**Architecture:** `bin/probe` only starts Docker. `probe/run.php` calls `ProbeRun::main`. A `Scheduler` walks the spec's bands and talks to an `Io` seam. Production `Io` is `curl_multi` plus non-blocking `proc_open`. Tests drive a fake `Io`.

**Tech Stack:** PHP 8.5 CLI in `log-read-php`, `ext-curl`, `pdo_sqlite`, `proc_open`, PHPUnit via `./bin/run`. No new Composer package.

**Spec:** `packages/web-app/doc/features/0005-probe/specs/probe.md` and `packages/web-app/doc/features/0005-probe/design/Probe.md`

## Global Constraints

- Commands run from `packages/web-app` through `./bin/run`. Do not use host PHP.
- No new Composer dependency. No Symfony HttpClient. No `pcntl`.
- The probe stays outside `src/`. Namespace `Yumo\Eleanor\Probe`, autoloaded from `probe/` in `autoload-dev`.
- `sample` is at most 10. The corpus is `var/log-urls.txt`. `sample.txt` in the run folder is only the draw.
- Eleanor HTTP statuses, and `archive:import` exit 0 or 1 with a summary, leave the probe exit at 0. A step that cannot be sent sets `error` and the other selected steps still run.
- The bearer secret is never written. `authorization` is `bearer`, `absent`, or `wrong`.
- `read` is not implemented. SQLite is not wiped. The owner email is the parameter `eleanor.owner_email`, read by booting `Yumo\Eleanor\Kernel` in `dev`.
- Server boot timeout 10 seconds. HTTP transfer timeout 60 seconds. Import child timeout 600 seconds.

## Review Focus

- An empty `ELEANOR_BEARER_TOKEN` exits non-zero and starts no server. Pinned in Task 6.
- A listen port already taken settles the server job with `error` and starts no step. Pinned in Task 5.
- Import exit 1 with `Written` on stdout is not a probe error. Any other non-zero import exit is. Pinned in Task 5.
- An HTTP 422 leaves the scheduler exit at 0. A transport failure sets `error`, leaves the exit non-zero, and still starts the next write. Pinned in Task 4.
- The run folder stores the authorization label and never the secret. Pinned in Task 3.

### Task 4: Scheduler

**Files:**
- Create: `packages/web-app/probe/Job.php`
- Create: `packages/web-app/probe/Settled.php`
- Create: `packages/web-app/probe/Io.php`
- Create: `packages/web-app/probe/Scheduler.php`
- Create: `packages/web-app/tests/Probe/FakeIo.php`
- Test: `packages/web-app/tests/Probe/SchedulerTest.php`

**Interfaces:**
- Consumes: `Catalog`, `Record`
- Produces:
  - `Job` readonly: `string $kind` one of `server`, `import`, `http`, `sql`; `string $name`; `?Preset $preset`; `?string $url`
  - `Settled` readonly: `Job $job`, `?int $status`, `?string $body`, `array $headers` of string to string, `?string $error`, `?int $exitCode`, `?string $stdout`, `?string $stderr`, `?string $errorLog`, `?array $rows`, `?string $sqlFile`
  - `Io::start(Job $job): void`, `Io::poll(): array` as `list<Settled>`, `Io::stop(): void`
  - `Scheduler::__construct(Io $io, Record $record, string $archiveUrl)`
  - `Scheduler::run(array $selected): int`

`FakeIo` records every `start` and the number of `poll` calls so far at that start. `script(string $name, Settled $settled)` supplies the outcome. `poll` returns the settles for jobs started since the previous poll, unless `hold(string $name)` is set, in which case that job stays in flight and is not returned.

Scheduler phases, matching the design:

1. Start one `server` job. Poll until it settles. `error` set: call `stop`, return 1, write no step.
2. Start every selected refusal and `import` if selected, then poll. Do not poll between those starts.
3. After `import` has settled or was not selected, start `archive` if selected. After `archive` has settled, start `archive-again` if selected. A settled `error` does not skip the next write. HTTP writes use `$archiveUrl`.
4. After every selected write has settled, start selected `list` and `sql`.
5. Poll until every selected step has settled. When `poll` returns empty and a job is in flight, `usleep(10000)` and poll again.
6. `stop` in a `finally`. Return 0 when every settled step has `error === null`. Return 1 otherwise.

`writeStep` uses the index of the name in `$selected` (1-based) and the spec's step shape: `name`, `request`, `response`, `log`, `import`, `sql`, `error`. HTTP fills `request` from the preset plus `$archiveUrl` for `archive` and `archive-again`. `log` is `[]` here. The production tail is Task 5. `import` and `sql` leave `request` and `response` null and fill their own key. A transport `error` leaves `response` null.

### Task 5: Curl and process Io

**Files:**
- Create: `packages/web-app/probe/ImportResult.php`
- Create: `packages/web-app/probe/CurlProcessIo.php`
- Test: `packages/web-app/tests/Probe/ImportResultTest.php`
- Test: `packages/web-app/tests/Probe/CurlProcessIoTest.php`

**Interfaces:**
- Consumes: `Io`, `Job`, `Settled`, `Catalog`
- Produces:
  - `ImportResult::error(?int $exitCode, string $stdout): ?string`. Null when `$exitCode` is 0 or 1 and `$stdout` contains `Written`. Otherwise a sentence. Null `$exitCode` returns a sentence.
  - `CurlProcessIo implements Io`
  - `CurlProcessIo::__construct(string $packageDir, string $runDir, string $ownerEmail, int $port, string $token, LogTail $log)`
  - `CurlProcessIo::databasePath(string $dataDir, string $email): string` returns `$dataDir . '/' . substr(hash('sha256', $email), 0, 16) . '.sqlite'`

HTTP `start` adds a `curl_multi` handle to `http://127.0.0.1:$port` plus the preset path. `CURLOPT_TIMEOUT` is 60. Authorization `bearer` sends `Authorization: Bearer ` plus the token. `wrong` sends `Authorization: Bearer wrong`. `absent` sends no such header. A finished handle with a curl error settles `error` and null `response`. A finished handle with any HTTP status settles `error` null, the status, the body, and headers `content-type`, `x-request-id`, and `allow` when present, names lowercased. `log` on the step is filled by the scheduler from `LogTail`; `CurlProcessIo` exposes `logLines(): array` as the new raw lines since the server settled. `Scheduler` already writes `log: []`. Change `Scheduler` to accept an optional `?LogTail` reader closure `Closure(): array` defaulting to `static fn (): array => []`, and pass `LogTail::forRequest` the lines and the response request id. Tests in Task 4 keep the default.

`import` is `proc_open(['php', 'bin/console', 'archive:import', $runDir . '/sample.txt', '--owner=' . $email], cwd: $runDir)` with non-blocking pipes. Settle through `ImportResult::error`. When `error.log` exists in the run directory, copy it into `Settled::$errorLog`. When it does not, `errorLog` is null. Do not kill this child because another step failed. Kill it from `stop` only if it is still running.

`server` is `proc_open(['php', '-S', '0.0.0.0:' . $port, '-t', 'public', 'router.php'], cwd: $packageDir)`. Poll until any HTTP response from `http://127.0.0.1:$port/` or the 10 second boot timeout. Timeout or a failure to bind settles `error`. `stop` sends `proc_terminate` to the server.

`sql` opens `databasePath($packageDir . '/var/data', $ownerEmail)` with `PDO::SQLITE_OPEN_READONLY`. One query joins `archive` to `archive_body` and selects `id`, `url`, `title`, `excerpt`, `site_name`, `created_at`, and `length(archive_body.html)` as `body_bytes`, filtered by `url`. Missing file or missing row settles `rows: []` and `error` null. It settles on the `poll` after `start`.

`probe.json` is the spec's default document: `urls` `var/log-urls.txt`, `sample` 10, `owner` `owner@example.com`, `port` 8000, and the step list `import`, `archive`, `archive-again`, `list`, `sql`, then the nine refusals.

`bin/probe` follows `bin/serve`: same image, same `container_fill_run_args`, plus `-e ELEANOR_BEARER_TOKEN`. It reads `port` with `python3` from `probe/probe.json`, default 8000, and publishes `127.0.0.1:$port:$port`. It execs `php probe/run.php` and appends the caller's arguments. Usage with more than one argument prints to stderr and exits 1 before Docker.
