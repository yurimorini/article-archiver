# Kernel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Boot `Yumo\Eleanor\Kernel` from the existing Eleanor Composer project on the Symfony 8.1 micro skeleton, and prove the test run sees the `test` environment.

**Architecture:** Flex installs the official 8.1 micro recipe into `packages/web-app`. Eleanor's only type is the recipe kernel, renamed to `Yumo\Eleanor\Kernel`. The service-resource prefix is renamed to `Yumo\Eleanor\`. The front controller and the console stay recipe entry points and boot that kernel. One PHPUnit test boots the kernel from the environment the test run set.

**Tech Stack:** PHP 8.5, Symfony 8.1 (framework-bundle, runtime, dotenv, yaml, console), Flex 2, existing PHPUnit 11, PHPStan, php-cs-fixer. Commands run through `./bin/composer`, `./bin/test`, `./bin/quality`, `./bin/cs-fix`, and `./bin/docker-run`.

**Spec:** `packages/web-app/doc/features/server/specs/Kernel.md`

## Global Constraints

- `Yumo\Eleanor\Kernel` is the only Eleanor type. The test namespace is `Yumo\Eleanor\Tests`.
- The only renames are the kernel class and the service-resource prefix `Yumo\Eleanor\`.
- Classes in `Yumo\Eleanor\` are services, with autowire and autoconfigure. The parameter section is empty. This slice defines no Eleanor service.
- Symfony framework-bundle, runtime, dotenv, yaml, and console are constrained to `8.1.*`. Flex's require setting is `8.1.*`.
- Contrib recipes stay off. Composer may run the Flex plugin and the runtime plugin. The ctype and iconv extensions are required.
- The website pack, Maker, the debug bundle, the web profiler, Monolog, and the PHPUnit bridge are not added.
- The kernel accepts `prod`, `dev`, and `test`. Dev is the default. The test run sets the environment to `test` and the secret to `test`.
- The shared env file commits `dev` and an empty secret. The dev env file commits a generated secret and is loaded only for dev. Machine-local env files, including the compiled local env file, stay off git. There is no secrets vault.
- The owner email, the bearer token, a database path, and an archive directory are absent from these env files.
- The session default, the shared-directory setting, the filesystem cache, the test block, and the dev error route stay as the recipe wrote them.
- Existing PHPUnit, PHPStan, formatter configuration, and quality scripts stay. Flex may add its cache-clear and asset-install scripts beside them.
- The recipe's editor settings stay. The agent-instruction files that recipe copies into the package are removed.
- The only PHPUnit seam boots the kernel and asserts the environment is `test`. It does not assert file contents, namespace strings, an HTTP status, or the boot failures.
- No glossary term. No ADR. A move to the next Symfony minor is out of scope.
- The library link `yumo/log-read` and `"php": "^8.5"` stay. `minimum-stability` and `prefer-stable` stay as they are.

## Review Focus

The spec describes these failures and forbids a second PHPUnit seam. Task 1 pins each with a one-shot `php -r` boot, not with `KernelTest`.

1. Environment `staging` fails during `boot()` with PHP's `InvalidArgumentException`, and the message names `getAllowedEnvs`.
2. Environment `""` fails in the constructor with PHP's `InvalidArgumentException`, and the message says the environment cannot be empty.
3. Environment `prod-eu` fails during `boot()` with PHP's `InvalidArgumentException`, and the message says the environment contains invalid characters.
4. A `prod` boot whose `APP_SECRET` is empty fails with `Symfony\Component\DependencyInjection\Exception\EmptyParameterValueException` while resolving `kernel.secret`.
5. A `prod` boot with `APP_SECRET` unset fails with `Symfony\Component\DependencyInjection\Exception\EnvNotFoundException`.

- [ ] **Step 2: Write the failing test**

Create `packages/web-app/tests/KernelTest.php`:

```php
<?php

declare(strict_types=1);

namespace Yumo\Eleanor\Tests;

use PHPUnit\Framework\TestCase;
use Yumo\Eleanor\Kernel;

/**
 * Boots Eleanor's kernel and reads the environment the test run set.
 */
final class KernelTest extends TestCase
{
    public function test_boot_sees_test_environment(): void
    {
        $environment = $_SERVER['APP_ENV'] ?? null;
        if (!is_string($environment)) {
            self::fail('APP_ENV must be a string.');
        }

        $kernel = new Kernel($environment, true);
        $kernel->boot();

        self::assertSame('test', $kernel->getEnvironment());

        $kernel->shutdown();
    }
}
```
