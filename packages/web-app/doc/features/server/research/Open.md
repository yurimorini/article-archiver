# Remaining sessions

The research queue is closed. A new session starts from [feature.md](../feature.md). That file is the goal, the backlog, and the slice in progress.

The table below is the record of the design sessions. A note is a direction until a slice spec adopts it. Do not append a new outcome to [Investigations.md](Investigations.md). That file is an early list of generic ideas, not this queue and not a mandatory order.

A session is an interview. The reader chooses the direction. Facts come from the code and from primary docs. The outcome is research, not a final decision. A later session can replace it. A spec adopts it when implementation starts. Terms that the session settles go in the package [GLOSSARY.md](../../../GLOSSARY.md). An ADR is written only when a choice would be hard to reverse, surprising without the context, and the result of a real trade-off. During research it stays proposed. An ADR for this package lives in [`adr/`](../../../adr/).
