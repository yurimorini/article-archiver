# Bearer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A matched `/api` route accepts only the configured bearer secret, and a missing secret is a 500 the log can name.

**Architecture:** `BearerAuthenticator` judges every request on a stateless `api` firewall. A match puts the configured email on an `EmailIdentity`. `AuthenticatedOwnerProvider` builds the `Owner` from that identity. `ErrorTranslator` writes the 401, and `TranslateApiException` stops propagation so Symfony does not replace it. An empty `ELEANOR_BEARER_TOKEN` throws `BearerNotConfigured` before the header is read.

**Tech Stack:** PHP 8.5, Symfony 8.1, `symfony/security-bundle` 8.1, PHPUnit 11, `./bin/test`, `./bin/quality`. Docker only.

**Spec:** `packages/web-app/doc/features/0002-server/design/Bearer.md`. The contract is `packages/web-app/doc/features/0002-server/specs/bearer.md`.

## Global Constraints

- No glossary term. No ADR. No second authenticator, JWT, cookie, password, role, or `WWW-Authenticate`.
- Firewall name `api`, pattern `^/api`, `stateless: true`, one custom authenticator, no entry point, no password hasher, no user provider. `access_control` is `{ path: ^/api, roles: IS_AUTHENTICATED }`.
- `ELEANOR_BEARER_TOKEN` uses an empty default. Missing and empty are the same. The committed `.env` does not set it. `.env.test` sets `test-bearer-secret`. The Owner's value belongs in `.env.local`.
- `eleanor.owner_email` stays. `OwnerProvider` aliases `AuthenticatedOwnerProvider`. `ConfiguredOwnerProvider` stays a class and is not the alias. `ArchiveServiceResolver` and `CreateArchiveController` do not change.
- 401 body is `{"code":"unauthenticated","message":"The request is not authenticated."}` as `application/json`. No `X-Request-Id`.
- 500 body for an empty secret is `{"code":"unexpected","message":"Something went wrong on the server."}`. The client sentence does not name the variable.
- Log lines, channel `application`: `bearer.absent` info, `bearer.rejected` info, `bearer.not_configured` error with context `variable` = `ELEANOR_BEARER_TOKEN`. No header value, no secret, no request id. Tests do not open log files.
- Scheme `Bearer` ignores case. The value after the first space is compared with `hash_equals` and is not trimmed.
- Docs and comments in English. Tests: `./bin/test web-app`. Final gate: `./bin/quality`. Commit scope `web-app`, Conventional Commits.
- `feature.md` already links this plan. Do not add a second link.

## Review Focus

1. `Authorization: Bearer <secret><space>` is 401, not 201. Task 1 `test_a_trailing_space_is_401`.
2. Scheme `bearer` in lowercase is accepted. Task 1 `test_lowercase_scheme_archives`.
3. A broken JSON body with no secret is 401, not 400. Task 1 `test_broken_json_without_a_secret_is_401`.
4. A kernel booted with the variable unset answers 500, and the body does not contain `ELEANOR_BEARER_TOKEN`. Task 2 `test_an_empty_secret_is_500_unexpected`.
5. A 201 does not send `Set-Cookie`. Task 1 `test_lowercase_scheme_archives`.

The three log lines are specified and the spec forbids reading them back. No task asserts them.

- [ ] **Step 5: Implement the types the interfaces block names**

`authenticate` reads the secret first. This task's secret is never empty; the empty branch is Task 2. Read `Authorization` with `$request->headers->get('Authorization')`. Null writes `bearer.absent` at info and throws `CustomUserMessageAuthenticationException` with message `Unauthenticated.` A present value splits on the first space only. No space means the whole value is the scheme and the candidate is `''`. The scheme matches `Bearer` by `strcasecmp`. The candidate is the exact substring after that first space. A mismatch writes `bearer.rejected` at info and throws the same exception. A match returns `new SelfValidatingPassport(new UserBadge($this->email, fn (string $email): EmailIdentity => new EmailIdentity($email)))`.

`AuthenticatedOwnerProvider::owner()` uses `Security::getUser()`. A `UserInterface` becomes `new Owner($user->getUserIdentifier())`. Anything else throws `\LogicException` with message `The call has no authenticated owner.`

`RequestFailure::Unauthenticated` is status 401 and message `The request is not authenticated.`

`ErrorTranslator` maps every `AuthenticationException` to that failure. It maps an `AccessDeniedException` to that failure when the token storage has no full authentication. Leave the constructor defaults so `new ErrorTranslator()` in the unit tests still works: token storage and the trust resolver are optional, and a missing token storage counts as not full. `BearerNotConfigured` is not this task. Any other throwable stays `unexpected`.

`TranslateApiException`, after `setResponse`, calls `$event->stopPropagation()` only when the reply code is `unauthenticated`.

`ConfiguredOwnerProvider`'s class docblock no longer says a later slice replaces it.
